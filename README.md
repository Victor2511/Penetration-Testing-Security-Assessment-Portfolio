## 📑 Report Structure Standard

All security assessments follow a rigorous enterprise structure:
1. **Executive Summary & Scope:** Business impact overview for non-technical stakeholders.
2. **Attack Chain Walkthrough:** Chronological progression from initial access to objective completion.
3. **Technical Findings Details:** Detailed reproduction steps, CWE mapping, CVSS 3.1 rating, and precise root-cause analysis.
4. **Prioritized Remediation Plan:** Actionable short-term, medium-term, and long-term security recommendations.
